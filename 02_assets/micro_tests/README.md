# 第 7 轮：确定修复规则的最小测试

## 覆盖范围

`diagnostic_rules.jsonl` 中有 31 条 `confidence == "high"` 规则，其中 10 条同时满足 `fix` 给出确定修复、且不包含“不自动修”。本目录为这 10 条各建一个测试文件，共 **10 个文件、10 条规则、10 个 pytest 用例**。

| 规则 | 最小反例与预期问题 | 应用规则修复后的预期结果 |
| --- | --- | --- |
| DR_0001 | `for` 语句头缺冒号，`compile` 抛 `SyntaxError` | 只补一个冒号后可编译，循环结果为 `[1, 2, 3]` |
| DR_0006 | 已有 `import math`，直接 `sqrt(9)` 抛 `NameError` | 改为 `math.sqrt(9)`，结果为 `3.0` |
| DR_0010 | 默认 list 的两次省略参数调用共享 `["a", "b"]` | 调用点显式传新建 list，两次结果分别为 `["a"]`、`["b"]`；显式共享传参语义不变 |
| DR_0013 | `input` 返回的字符串直接加 1，抛 `TypeError` | 插入 `age = int(age)` 后，输入 `8` 得到整数 `9`；非法数字仍抛 `ValueError` |
| DR_0014 | `"38.5"` 执行 `astype(int)` 抛 `ValueError` | 改为 `astype(float)`，值、dtype、总和 `78.5`、均值 `39.25` 均正确 |
| DR_0018 | 在模拟 GBK 默认编码环境中隐式打开 UTF-8 中文文件，抛 `UnicodeDecodeError` | 显式 `encoding='utf-8'` 后逐字还原，原文件字节不变 |
| DR_0019 | 本地 `requests.Response` 错用 GBK 解码 UTF-8 JSON，中文乱码 | 读取 `.text` 前设为 UTF-8，中文与 JSON 字段还原，原始 `content` 不变 |
| DR_0022 | 裸 `except` 把注入的 `NameError` 也错报成“文件不存在” | 只捕获 `FileNotFoundError`；缺失文件仍兜底，正常读取不变，其他异常向外传播 |
| DR_0025 | 注入读取异常时，直线 `open/readline/close` 的关闭次数为 0 | 改为 `with` 后正常结果不变，异常仍传播且关闭恰好一次 |
| DR_0029 | `groupby("桌号")` 在真实列 `"桌 号"` 上抛 `KeyError` | 唯一空白候选用于代码访问，分组和正确；输入 DataFrame 列名不变 |

## 怎么运行

在项目或分发包根目录执行：

```powershell
python -m pytest 02_assets/micro_tests/
```

- **预期通过数：10 passed，0 failed。**
- 本轮最终实测：**10 passed，0 failed，通过率 100%（10/10）**。
- 另将 10 个文件分别交给 Python 直接运行，实测 **10/10 PASS**。

单个文件既可由 pytest 运行，也可直接运行，例如：

```powershell
python -m pytest 02_assets/micro_tests/test_DR_0001.py
python 02_assets/micro_tests/test_DR_0001.py
```

测试使用 Python 标准库以及项目当前环境中的 `pandas`、`requests`；HTTP 规则只构造本地响应，不访问网络。每个文件都有自己的 `test_DR_XXXX()` 和 `if __name__ == "__main__"` 入口，不依赖共享测试辅助模块。
