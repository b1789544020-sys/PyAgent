## 真实浏览器流程

完整项目及公开展示排练均使用真实 Edge 与本地 HTTP 服务，而不是静态截图拼接。覆盖：

- TXT、Markdown、DOCX 导入与 DOCX 文字转换；
- 拖放、同名同内容复用、自动增量索引与真实向量生成；
- 混合检索、Qwen 回答、有效引用和全文段落高亮；
- 证据不足时的 `refusal / not_run`；
- 资料搜索、筛选、分页和备份式移除；
- 明暗主题、390×844 手机布局、移动侧栏及零 JavaScript 异常。

公开视频只采用实际成功且内容经过核查的生成结果。排练中出现的引用格式失败和模型等待不会被冒充为成功的生成回答；失败记录保留在私有验收材料中。
